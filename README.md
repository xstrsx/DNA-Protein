# 从 DNA 到蛋白质 · 3D 电影式细胞分子之旅
> **DNA to Protein: A Cinematic 3D Molecular Journey through the Eukaryotic Cell**

电影级一镜到底（One-shot Cinematic Experience），基于 WebGL (Three.js) 与 Web Audio API 原生程序化合成音乐引擎，全景再现真核生物中心法则全流程与蛋白质全生命周期。

---

## 🌟 核心生命机制全流程

### 1. ① DNA 复制 (Replication)
- **解旋酶打开双螺旋**：复制叉展开，两条母链同时作为模板。
- **子链合成**：DNA 聚合酶连续合成前导链，分段合成滞后链（冈崎片段）。
- **半保留复制**：准确传递遗传密码，子代双链包含一条母链与一条新链。

### 2. ② 转录与 pre-mRNA 剪接 (Transcription & Splicing)
- **转录延伸**：RNA 聚合酶以模板链为蓝本按碱基互补配对合成单链 pre-mRNA（含尿嘧啶 U）。
- **剪接体装配与套索切除**：真核生物多亚基剪接体（snRNP 复合体）识别剪接位点，弯曲内含子形成经典 **2'-5' 磷酸二酯键套索结构 (Lariat)**，催化切除内含子并实现 **外显子精准缝合 (Exon Ligation)**。
- **核孔转运出核**：拼接完成并带有保护修饰的成熟 mRNA 穿过核孔复合体进入细胞质。

### 3. ③ 翻译与空间折叠 (Translation & Folding)
- **核糖体装配与成肽**：核糖体大、小亚基合拢识别起始密码子，携带相应氨基酸的 tRNA 进入 A/P 位，脱水缩合形成肽键。
- **出口通道与终止**：多肽链穿过多肽出口通道 (Exit Tunnel) 持续延伸，释放因子 (RF) 识别终止密码子催化水解解离。
- **多级空间折叠**：
  - **一级结构**：疏水/亲水侧链 R 基团与苯丙氨酸芳香环排布；
  - **二级结构**：主链氢键网络驱动形成稳定 α-螺旋与 β-折叠；
  - **三级结构**：疏水核心塌缩、二硫键共价交联与带电侧链盐桥建立，展现成熟天然 Ribbon 构象。

### 4. ④ 伴侣辅助与质量控制 (Chaperone & Quality Control)
- **分子伴侣保护腔**：伴侣蛋白提供隔离微环境，水解消耗 ATP 辅助新生肽链正确折叠，防止错误聚集。
- **26S 蛋白酶体降解回收**：错误折叠或受损的蛋白质被打上多聚泛素 (Poly-Ubiquitin) 标记，送入 26S 蛋白酶体腔内水解为短肽与氨基酸原料回收利用。

### 5. ⑤ 翻译后修饰与四级结构 (PTMs & Quaternary Assembly)
- **共价化学修饰 (PTMs)**：信号肽剪切切除；添加高能磷酸基团（-PO₄²⁻ 磷酸化修饰）与核心寡糖链。
- **多亚基组装与协同催化**：独立折叠的亚基 A 与亚基 B 通过疏水界面和二硫键组装为完整四级结构二聚体复合物，呈现协同变构效应与催化活性中心。

### 6. ⑥ 高尔基体分选与 SNARE 膜融合胞吐 (Golgi Trafficking & SNARE Exocytosis)
- **高尔基体扁平囊叠层加工**：运输囊泡穿越细胞质，进入高尔基体顺面囊 (cis) $\to$ 反面网 (TGN)，寡糖链完成复杂天线修饰成熟。
- **SNARE 蛋白机械绞合**：分泌小泡抵达质膜内侧，4 根 SNARE 螺旋绞合成束并产生强大牵引力拉近双层膜。
- **质膜融合与胞吐**：质膜融合孔打开，囊泡膜与细胞膜融合，伴随能量爆发光芒将成熟功能蛋白质分泌至 **细胞外环境 (Extracellular Space)**。
- **全景宏大终章**：镜头从胞外拉远，全景鸟瞰包含细胞膜、细胞质、高尔基体、线粒体、内质网与细胞核的真核细胞全貌。

## 🎵 电影级原生合成配乐 (Web Audio API)

- **纯代码数学合成**：无需加载任何外部 MP3/WAV 资源，通过振荡器、双二阶滤波器、立体声混响冲激响应与乒乓延时实时生成。
- **乐章情绪流动**：
  - `0 - 17s`：D Lydian 序章（空灵深邃、微孔水滴泛音）
  - `17 - 56s`：Bm9–Gmaj7 复制乐章（精密严谨的分子律动与交替琶音）
  - `56 - 108s`：Em9–Cmaj7 转录与剪接（流动抒情木管旋律与剪接能量闪光泛音）
  - `108 - 142s`：Dmaj9 翻译装配（灵动跳跃的成肽缩合节奏）
  - `142 - 222s`：Gmaj9–F#m7–Dmaj9 宏大交响（蛋白质多级成熟、跨膜胞吐与全貌全景终章）
